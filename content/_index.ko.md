LLM 애플리케이션의 보안 쪽 일을 합니다 — 모델 질의 엔드포인트 인증, 생성된 SQL의 SSRF 가드, 프롬프트 로그의 PII 마스킹, 그리고 모델 출력을 내보내도 되는지 판정하는 평가 게이트.

일 밖에서는 같은 종류의 시스템을 처음부터 만듭니다. 그래야 무엇이 실제로 버티는지 알 수 있기 때문입니다.

### 주요 작업

**자작 XDR** — 수집·탐지·분석·대응 4계층을 한 대의 호스트에 올리고, 6단계 자동 대응 체인과 SOC 콘솔을 붙였습니다. 컨테이너 10개, 외부 노출 포트는 1개.

**Go로 다시 지은 SIEM** — 상용 SIEM이 다루는 기능 축을 Go 마이크로서비스 11개로 처음부터 다시 지었습니다. 탐지 룰 DSL과 그 파서를 직접 만들었습니다.

**User-mode EDR 센서** — C++ 2,840줄로 Ring 3에서 프로세스·파일·네트워크·레지스트리를 관측합니다. Ring 3가 어디서 한계에 부딪히는지 확인하려고 만들었고, Sysmon 기준으로 자체 채점해 사각을 공개했습니다.

**온프레미스 LLM 에이전트 콘솔** — 엔진은 고정하고 도메인을 교체합니다. 프롬프트·지식·모델이 카트리지이고, 설치 시 하드웨어 티어를 감지해 모델 프리셋을 고릅니다.

### 논문

**김강민**, 변현수, 조민정, 김역, 손기욱, 이창훈 (2025). *디지털 포렌식 관점에서의 Threads 사용자 행위 분석.* 한국정보보호학회 동계학술대회 논문집(CISC-W'25), 제35권 제2호.

**KISTI 한국과학기술정보연구원 원장상** 수상. 제1저자. 루팅된 안드로이드 기기에서 열람 게시물, DM 본문, 팔로우 관계, 인앱 검색 기록을 복원했습니다 — 본 DB만 보는 절차라면 놓쳤을 WAL(선기록 로그)까지 포함해서.
